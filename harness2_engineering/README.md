# Harness Engineering

This repository contains separate Go and Rust implementations of the Gemini
command-line example:

- [Go implementation](./harness_engineering_go/)
- [Rust implementation](./harness_engineering_rs/)

Each implementation has its own README and `.env.example`. Create a local
`.env` in the implementation directory you want to run, set `GEMINI_API_KEY`,
and follow that directory's instructions. Alternatively, export the variable
in your shell before running the application.
